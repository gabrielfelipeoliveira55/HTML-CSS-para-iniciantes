# Exercício: Projeto Cinema

### 1. Estrutura do Projeto
1. Crie um projeto chamado `cinema`.
2. Crie um diretório dentro do projeto com o nome: `estados`.
3. Crie um diretório dentro do projeto chamado `css`.

---

### 2. Página Inicial (`index.html`)
* **2.1** O título do arquivo (`<title>`) e o título de nível 1 (`<h1>`) devem conter o nome do projeto (`cinema`).
* **2.2** Crie um link para cada estado/cidade na página inicial.
  * **2.2.1** O link deve estar dentro de um título de nível 2 (`<h2>`).

---

### 3. Páginas dos Estados (`rj.html` e `sp.html`)
Dentro do diretório `estados`, crie os arquivos `rj.html` e `sp.html`:

* **3.1** Adicionar um link levando para o início do site (`index.html`).
* **3.2** Adicionar um título de nível 1 (`<h1>`) com o nome do estado.
* **3.3** Adicionar os seguintes parágrafos (cada filme deve ser um parágrafo individual):

#### **Rio de Janeiro (`rj.html`)**
* Lisbela e o Prisioneiro - 20:00 - Hoje
* Meu nome não é Jhonny - 21:00 - Hoje
* O Cheiro do ralo - 15:00 - Amanhã

#### **São Paulo (`sp.html`)**
* Lisbela e o Prisioneiro - 20:00 - Hoje
* Meu nome não é Jhonny - 21:00 - Amanhã
* O Cheiro do ralo - 15:00 - Amanhã

---

### 4. Estilização (`css/style.css`)
Crie um arquivo de estilo dentro do diretório `css`.

* **4.1** Vincule (`<link>`) o arquivo de estilo em todas as páginas do site.
* **4.2** Mude a cor dos filmes que estreiam **hoje** para `darkred`.
* **4.3** Mude a cor dos filmes que estreiam **amanhã** para `darkblue`.
* **4.4** Remova o sublinhado de todos os links do site (`text-decoration: none`).
* **4.5** Mude a cor dos links que estão dentro do título de nível 2 (`h2 a`) para `seagreen`.
* **4.6** Aumente a fonte dos parágrafos para `20px`.
* **4.7** Mude a família da fonte de todo o site para `Arial`, `sans-serif`.
